ARCHITECTURE DECISION RECORD 0006 · DEFERRED

A2A routing and identity: deferred

This record has no active decision. A2A implementation is deferred, because it does not fit the current requirements, and the proposal that used to be on this page now lives in the Deferred ADRs section. The number and this address are kept so existing links still work.

Disposition
Deferred 2026-11-08 at the user's request, as relayed by the operator USER. Not accepted, not rejected, not superseded. It is not a requirement, and no active record depends on it.
Why
Fit. A2A's task semantics do not match the main current need, direct conversational peer messaging. This is not a claim that A2A cannot carry messages.
Where the rest is
The deferral record (reasons, what was built, findings, when to reopen) and the preserved proposal (the former text of this page). Index: Deferred ADRs.
